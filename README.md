# RxGrowth IQ

**Pharmaceutical Prescription Growth Intelligence Platform** — measures brand performance
across the full sales hierarchy, mathematically decomposes *why* growth happened, predicts
which prescribers will grow, and recommends next-best-actions for field reps.

> ⚠️ **Synthetic data only.** This repository contains no real prescription, patient, or
> licensed vendor data, and never will. All data is generated by `packages/synth`. See
> [`docs/compliance.md`](docs/compliance.md) before adapting this for production use.

---

## What it does

| Capability | Detail |
|---|---|
| **Measure** | TRx / NRx / NBRx / market share at national → region → district → territory → prescriber |
| **Explain** | Growth decomposed into market growth vs. share gain, and writer breadth vs. depth |
| **Predict** | Prescriber growth propensity, decline risk, and causal call uplift |
| **Recommend** | Ranked weekly next-best-actions per rep, with reasoning and constraint gating |
| **Narrate** | Plain-English insight via Claude, grounded strictly in computed numbers |

## The flagship feature

Most Rx analytics can tell you TRx went up 8%. This decomposes it:

```
delta_B = market_effect + share_effect + interaction
          S0*(M1-M0)     M0*(S1-S0)     (M1-M0)*(S1-S0)
```

...and asserts the identity holds to 1e-9 under property-based testing. The interaction term
is silently dropped in most spreadsheet implementations, which is why their numbers never
quite reconcile.

## Quickstart

Requires Python 3.12+, Node 20+, and [uv](https://docs.astral.sh/uv/). No Docker —
see [ADR 0001](docs/ADR/0001-architecture.md) decision 9.

```bash
uv sync          # install the Python workspace
uv run dev       # API on :8000, web on :3000 (installs web deps on first run)
```

### Tasks

`make` is replaced by `uv run <task>` — same ergonomics, no extra dependency.

| Task | Does |
|---|---|
| `uv run dev` | API + web together |
| `uv run api` / `uv run web` | One service, clean logs |
| `uv run test` | pytest with coverage |
| `uv run lint` / `uv run fmt` | ruff check / autofix |
| `uv run typecheck` | mypy `--strict` + `tsc --noEmit` |
| `uv run guard` | Scan the diff for real-data indicators |
| `uv run check` | **Every gate CI runs.** Use before pushing. |

`uv run seed` and `uv run dbt-build` arrive in Phase 1 with the synthetic generator.
